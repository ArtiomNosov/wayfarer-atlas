# Оригинальная графика магазина

`icon.png`: 512×512, RGBA 32-bit. `feature-en.png` / `feature-ru.png`: 1024×500, RGB. Рядом редактируемые SVG. Это оригинальные иллюстрации проекта, не скриншоты приложения или Google Play.

Рабочие названия могут быть заменены после проверки окончательного бренда. В `screenshots/` находятся восемь настоящих кадров версии **0.1.1 (2)**, по четыре на RU/EN. Перед загрузкой проверьте версию в capture-metadata.json, формат файлов и их соответствие манифесту. Нельзя выдавать иллюстрации, схемы инструкции или макеты за снимки работающей версии.

## Требования к настоящим кадрам

Снимайте работающий APK/AAB на эмуляторе или устройстве. Время, язык и наполнение на изображении должны соответствовать сборке. Используйте придуманные для теста записи поездок, без личных записей пользователей. Укажите в каталоге версию/код приложения, устройство/Android, язык, экран и имя файла.

Формат: JPEG или 24-bit PNG без alpha, стороны 320–3840 px, длинная сторона не больше двух коротких. Для этого проекта рекомендуемый размер 1080×1920. Подготовьте карту, сравнение гражданств, рейтинг и журнал поездок отдельно на RU/EN. Кадр ошибки или неподключённой функции не подтверждает готовность этой функции.

Схемы в `../illustrations/` объясняют работу Play Console и приложения. Они остаются схемами и не входят в каталог снимков экрана.

## Каталог 0.1.1 (2), 26.10.2026

Съёмка выполнена в настоящей MainActivity 0.1.1 (2) на Android ATD arm64 / API 36 через официальный Compose `captureToImage`; AndroidX временно включает рендеринг ATD. Время съёмки — `2026-10-26T07:54:25.514192Z`. Размер каждого кадра — 1080×1920. Использованы настоящие встроенные/проверенные справочные данные, журнал поездок пустой. При экспорте в 24-bit RGB удалён непрозрачный alpha-канал; все RGB-пиксели совпали с оригиналами. Это снимки native-интерфейса, без дорисовки экранов. Съёмка debug/test варианта не заменяет отдельную проверку release APK, которая отражена в [отчёте 0.1.1](../../verification-0.1.1.md).
