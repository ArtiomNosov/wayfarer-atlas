## Действия владельца перед загрузкой в Console

- [ ] Указаны реальная страна и тип издателя, имя/наименование, рабочий публичный email поддержки и дата политики.
- [ ] Страна поддерживается, Play Console зарегистрирована и верифицирована; при необходимости выполнено подтверждение физического Android-устройства.
- [ ] Рабочий package `org.wayfarer.atlas` принят как постоянный идентификатор до первой загрузки; доступность бренда проверяется отдельно.
- [ ] Владелец сохранил защищённую резервную копию всего уже созданного `release-private/`. Ключ не пересоздаётся, каталог не включается в Git/чат/публичный архив.
- [ ] Окончательная политика без плейсхолдеров размещена по HTTPS без входа; её URL внесён в приложение и Console.
- [ ] В Console перенесены [подготовленные ответы Data safety](data-safety-checklist.ru.md), решён узкий вопрос категории технических соединений GitHub/HK; сведения совпадают с финальным релизом.
- [ ] Заполнены app access, ads, target audience, IARC и остальные обязательные анкеты; возрастной рейтинг не выдуман заранее.
- [ ] Загружены RU/EN карточки, иконка, feature graphic и минимум два настоящих кадра приложения.
- [ ] Выбраны страны распространения и бесплатная модель; нет рекламы, покупок и подписок.

## Повторная проверка через Google Play и на устройствах

Этот раздел относится к Console, участникам и другим устройствам. Он выполняется после соответствующих локальных проверок текущей версии и не заменяется одним эмуляторным прогоном.

- [ ] Подписанный AAB установлен через внутренний тест Google Play; проверены свежая установка и обновление.
- [ ] Изучен pre-launch report, устранены обнаруженные критические падения/блокеры.
- [ ] На физическом телефоне проверены RU/EN, поездки, уведомления, offline/обновление и ограничения энергосбережения.
- [ ] Дополнительно проверены API 26, маленький/большой экран, увеличение шрифта и полный TalkBack. Их не считают пройденными только по API 36 эмулятору.
- [ ] При необходимости подтверждена runtime-работа на устройстве с 16 KB страницами. Статические результаты новой сборки сверяются с отчётом; runtime 16 KB отдельно не считается проверенным.
- [ ] Если применимо, закрытый тест выполнил 12 непрерывных подключений минимум 14 дней и Google выдал production access.
- [ ] Владелец просмотрел итоговый набор изменений и управляет отправкой на проверку и моментом публикации.

## После одобрения

- [ ] Публичная страница и установка доступны в выбранных странах.
- [ ] Работают контакт поддержки, политика и обновления справочников.
