## История: проверка 0.1.0

Это отдельный технический прогон, который **не считается закрытым тестом Google Play** и не заменяет участников 12/14. Версия 0.1.0 (1), `org.wayfarer.atlas`, Android 16 / API 36, Android ATD arm64. Android UI-тесты: 9/9; 78 offline-проверок логики/парсера/хранения, 7 наборов JVM-тестов и lint прошли. Подпись release APK, ELF/RELRO и выравнивание ZIP 16 KB проверены; bundletool validate прошёл. Runtime с 16 KB страницами отдельно не проверен. Живая загрузка обновления с разрешённого GitHub-хоста выполнена; перенаправления отключены. Подробные результаты и ограничения — в [verification.md](../verification.md).

Для 0.1.0 были сняты восемь реальных native-кадров интерфейса RU/EN 1080×1920, без записей поездок; результат отражён в [историческом отчёте](../verification.md). Каталог изображений обновляется для текущей версии, её происхождение проверяется по [метаданным съёмки](store-assets/screenshots/capture-metadata.json) и [манифесту с SHA-256](store-assets/screenshots/manifest.json). Кадры не доказывают доставку уведомлений, отсутствие сетевых ошибок или прохождение закрытого тестирования.

Signed release APK отдельно установлен на эмулятор: локальное уведомление фактически доставлено. Затем поездка удалена через UI с подтверждением, без force-stop; журнал пуст, активных уведомлений приложения осталось 0. Установка из Play, pre-launch report, живые отзывы тестировщиков и проверка на физическом телефоне ещё требуют выполнения владельцем.

## Проверка новой версии 0.1.1 (2)

Финальный build SUCCESS; 106 поведенческих сценариев (69 прежних Java + 20 новых Java + 17 Python). Gradle: 10 suites / 27 JUnit, без ошибок. Android UI: 14 PASS, 1 optional screenshot tool SKIP, 0 failures/errors; три onboarding и два HK regression прошли. Lint debug/release: 0 ошибок, 19 предупреждений. Подписи финальных APK/AAB, ELF/RELRO/ZIP alignment и bundletool прошли; хеши записаны в [отчёте артефактов](artifact-verification.json). Реальное signed-обновление 0.1.0 → 0.1.1 сохранило тестовый журнал; ознакомление с предупреждением сохранилось после перезапуска. Результаты отражены в [verification-0.1.1.md](../verification-0.1.1.md).

На подписанной 0.1.1 подтверждены RU→HK 14 дней с официальной ссылкой, четыре источника в Settings и HK sourceAsAt 2025-12-31. Живые загрузки прошли: community `2026-10-26T07:52:31.054792Z`, HK `2026-10-26T07:52:34.256599Z`. После холодного запуска сохранены оба кэша, их метки времени, HK sourceAsAt и RU→HK 14 дней. Это время получения файлов, не дата проверки каждого визового правила. Синтетическая поездка удалена через UI; после перезапуска журнал пустой.

Автоматические проверки покрывают обязательность предупреждения на RU/EN, его сохранение и повторное открытие, источники HK/NZ/MO, приоритет происхождения и консервативные UNKNOWN. NZ/MO отображаются как встроенные сведения, обновляемые с версиями приложения. Manifest и зависимости проверены: новых permissions/SDK и функций аккаунтов/облака/документов/OCR/рекламы/покупок нет; пользовательские записи исключены из Android backup/device transfer.

Восемь новых кадров настоящей MainActivity 0.1.1 (2) сняты на API 36 в `2026-10-26T07:54:25.514192Z`. Все 1080×1920, экспортированы в 24-bit RGB; RGB-пиксели не изменены, SHA-256 сверены с [manifest](store-assets/screenshots/manifest.json). Журнал на кадрах пустой. Съёмка не подменяет проверку доставки уведомлений: её исторический результат 0.1.0 описан выше; новая многодневная доставка для 0.1.1 отдельно не проверялась.

Данные издателя, трек, участники 12/14, отзывы, pre-launch report и установка из Play остаются отдельными действиями владельца.
