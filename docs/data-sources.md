## Приватность и воспроизведение

Два runtime-хоста: raw.githubusercontent.com и www.immd.gov.hk. Только явное нажатие пользователя, HTTPS, без redirects, ограничение размера, отдельные AtomicFile-кеши. Передаются общие запросы без гражданства, поездок, заметок, аккаунтов или стабильных идентификаторов; инфраструктура хостов видит IP/время и HTTP metadata. NZ/MO не вызывают сеть. Удаление журнала не изменяет общие справочные данные.

Генерация: `python3 data/prepare_official_data.py`; упаковка: `python3 scripts/sync-assets.py`. Исходные metadata и атрибуция: `data/official-sources.json`, `data/official-attribution.txt`, `data/sources/`. [Точный CSV-контракт](../data/official-data-readme.md). Лицензии доступны в приложении. # Бесплатные источники данных Wayfarer Atlas

Фактическая загрузка и проверка: 25 октября 2026 года. Приложение использует
бесплатные открытые справочные срезы и анонимный HTTPS-адрес обновления. Аккаунты,
пользовательские API-ключи, сервер приложения и платные квоты для этого не нужны.
Журнал поездок и напоминания хранятся локально и не отправляются источникам.

250 кодов справочника включают территории и не означают 250 отдельных гражданств.
Выбор гражданства ограничивается кодами, представленными в исходной матрице.
Для рейтинга используется одинаковый набор направлений источника. Остальные
территории можно использовать в журнале поездок, а неизвестные визовые пары
отображаются как `UNKNOWN`.

Natural Earth — обобщённая карта с фактическими границами из исходного набора.
Малые территории могут не иметь полигона при масштабе 1:110m. Два объекта без
назначенного кода не включены; подставные контуры не создавались. Координаты
`centroidLon`/`centroidLat` в справочнике стран остаются `null`: приложение рисует
реальную геометрию, а не выдуманные центры.

## Достоверность визовых условий

Включена версия VisaChecker **2026-08-11**, поле `updated` исходника —
**2026-08-10**, commit `3287b1d867d73507e5794f11c17e5df4ed11b36d`.
Скачанный файл сверен с Git blob hash закреплённого commit:
`11aaef005c78fe022abb09b62def256ea94d3e0e`.

Это открытый общественный справочник. Его базовая матрица —
[imorte/passport-index-data](https://github.com/imorte/passport-index-data)
(MIT, срез 2026-02-17), исторически полученная с passportindex.org. Слой исправлений
VisaChecker добавляет официальные ссылки и реальные даты отдельных проверок.
**Только 177 строк содержат первичный источник, и только 38 — дату проверки**
(от 2026-05-11 до 2026-08-10). Остальные строки не выдаются за индивидуально
проверенные или гарантированно актуальные. Дата загрузки не становится датой
проверки правила. Первичные страницы не перепроверялись нами для всех пар.

Область данных: обычный паспорт, туризм, один въезд, прямое прибытие, без транзита.
Дипломатические документы, работа/учёба, ВНЖ, транзит, требования к сроку действия
паспорта, обратному билету, средствам и другие условия допуска этим срезом не
описываются. `maxStayDays` не выражает скользящие ограничения вроде «90 за 180»;
`null` означает отсутствие опубликованной длительности, а не ноль или бессрочный
въезд. Число дней сохраняется для любой категории, если оно есть в источнике;
максимум в полученном срезе — 730 дней.

176 первичных ссылок используют HTTPS. Одна исходная ссылка использует HTTP;
её протокол не изменён догадкой: она сохранена текстом в примечании, а активная
ссылка ведёт к репозиторию набора. Отсутствующая первичная ссылка также ведёт к
репозиторию с явной отметкой об отсутствии индивидуальной проверки.

Категории не объединяются: `VISA_FREE`, `VISA_ON_ARRIVAL`, `ETA`, `E_VISA`,
`VISA_REQUIRED`, `RESTRICTED`, `UNKNOWN`. Неизвестное новое значение не считается
безвизовым. Рейтинг приложения — собственный счётчик
`VISA_FREE + VISA_ON_ARRIVAL + ETA` с раздельными деталями; это не официальный
Henley или Passport Index и не гарантия допуска к границе.

## Обновление в приложении

`data/update-source.json` задаёт публичный raw JSON и разрешённый хост
`raw.githubusercontent.com`. Формат — `visachecker-community-v1`.
`CommunityMatrixParser` преобразует реальную вложенную схему VisaChecker в
каноническую схему приложения; сохраняет `verified` только как `checkedAt`,
даты отсутствующих проверок оставляет `null`. Нормализованный результат повторно
проходит `DatasetParser`: коды, даты, длительности, источники и пары проверяются
до замены рабочего кеша. Невалидный или неполный ответ не должен заменять
сохранённую базу. Телефон обращается только по явной команде обновления;
пользовательские поездки, напоминания и гражданство в URL не передаются.

GitHub — публичный хостинг файлов, а не сервис с гарантией доступности или
проверки въезда. При отсутствии сети встроенный срез остаётся доступным.
Открытая лицензия разрешает коммерческое распространение с атрибуцией; отдельная
регистрация или согласие на включение этого среза не требуется.

## Атрибуция и воспроизводимость

`data/data-attribution.txt` содержит автора, ссылки на набор и лицензию,
обозначение внесённых изменений и происхождение базовой матрицы. Полные полученные
уведомления находятся в `data/Unicode-3.0.txt`,
`data/sources/visa-requirements-CC-BY-4.0.txt` и
`data/sources/passport-index-MIT.txt`. Эти уведомления включаются в лицензии
приложения. Это атрибуция источников, без заявления об их одобрении приложения.

Сырые файлы сохранены в `data/sources/`. URL, UTC-время получения, размеры,
SHA-256, commit и Git blob hash записаны в `data/download-manifest.json`;
покрытие и ограничения — в `data/provenance.json`.

```sh
cd apps/wayfarer-atlas
python3 -m unittest discover -s data/tests -v
python3 data/fetch_public_data.py --geometry --community-visa
python3 scripts/sync-assets.py
bash scripts/test-data.sh
```

Загрузчик получает commit перед скачиванием и использует закреплённый raw URL,
сохраняет лицензионные уведомления и проверяет минимум 190 гражданств и 35 000
распознанных правил перед заменой нормализованного среза. Источник и форматы
проверены на реальных загруженных данных. Проверки Java-адаптера покрывают
сохранение первичной ссылки и реальной даты, неизвестные категории, HTTP-ссылку,
невалидные даты/коды/длительности и ошибку лицензии.

## Невыбранные сервисы

Дополнительные коммерческие, sandbox- или MCP-API не подключены: для функций
первой версии достаточно перечисленных бесплатных источников. Данные и API
исследованного закрытого приложения не используются. Гарантированный мировой
официальный визовый feed с неограниченным бесплатным production-доступом не найден;
справочный характер и реальный возраст community-данных видны пользователю.
