# Wayfarer Atlas 0.1.1 / Атлас маршрутов

Android 8.0+, русский и английский интерфейс. Без аккаунтов, рекламы, покупок и облачной синхронизации.

## Скачать и установить

- [APK для установки на Android](https://github.com/ArtiomNosov/wayfarer-atlas/releases/download/v0.1.1/wayfarer-atlas-0.1.1-release.apk)
- [Инструкция пользователя с картинками](https://github.com/ArtiomNosov/wayfarer-atlas/blob/main/docs/user-guide.ru.md)
- [English user guide](https://github.com/ArtiomNosov/wayfarer-atlas/blob/main/docs/user-guide.en.md)

Для обновления установите release APK поверх прежней версии, не удаляя приложение. Сохранение локального журнала при переходе 0.1.0 → 0.1.1 проверено. Удаление приложения удаляет журнал.

## Изменения

- Четыре источника справочника: community, Hong Kong Immigration Department, проверенный список Immigration New Zealand и фактическая сводка правила Россия → Макао по официальному источнику.
- Исправлено Россия → Гонконг: обычный паспорт, краткое посещение, без визы до 14 дней; показаны условия и официальный источник.
- Community и HK обновляются по кнопке с отдельными кешами. NZ/MO обновляются с выпуском приложения. Дата состояния HK CSV2025-12-31 отделена от даты его загрузки.
- Предупреждение при первом запуске на RU/EN: данные могут быть неполными, неточными или устаревшими; перед решениями о поездке нужно сверить официальные требования. Подтверждение сохраняется, повторный просмотр доступен в настройках.

Подписанные APK/AAB проверены локально; сохранение журнала, оба live-обновления и холодный запуск проверены на Android36 эмуляторе. Прошли106 поведенческих проверок и14 функциональных Android-сценариев. [Подробности и границы проверки](https://github.com/ArtiomNosov/wayfarer-atlas/blob/main/docs/verification-0.1.1.md).

## Остальные файлы

AAB предназначен для Play Console, а debug APK — для разработки. Приложение пока не опубликовано в Google Play. Архив исходников не содержит ключей подписи или локальных credentials. SHA-256 всех четырёх файлов записаны в `SHA256SUMS.txt` и `manifest.json` в Assets.

## English

Download the `-release.apk` asset to install on Android8.0+. Install it over the previous signed release to retain the local travel journal; do not uninstall first. The app supports Russian and English, works with bundled data offline, and has no accounts, ads, purchases or cloud sync.

Version0.1.1 adds government sources for Hong Kong and New Zealand plus a reviewed Russia–Macao rule, corrects Russia–Hong Kong to visa-free14 days for ordinary short visits, and adds a first-launch travel-information notice. Community/HK data refresh with the update button; NZ/Macao snapshots update with app releases. Always verify current requirements with official authorities before making travel decisions.

The signed release was tested locally, including an in-place upgrade, journal retention, both live data feeds and cold-start persistence. See the [verification report](https://github.com/ArtiomNosov/wayfarer-atlas/blob/main/docs/verification-0.1.1.md). GitHub Actions build outputs are separately labelled debug or unsigned; installable signed builds are distributed in Releases.
