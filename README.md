[![Android CI](https://github.com/ArtiomNosov/wayfarer-atlas/actions/workflows/android.yml/badge.svg)](https://github.com/ArtiomNosov/wayfarer-atlas/actions/workflows/android.yml)

**[Скачать APK / Download APK](https://github.com/ArtiomNosov/wayfarer-atlas/releases/latest)** · **[Инструкция пользователя](docs/user-guide.ru.md)** · **[English user guide](docs/user-guide.en.md)**

Карта условий въезда, сравнение гражданств, рейтинг доступности и личный журнал поездок с напоминаниями. Нативное приложение для **Android 8.0+**, русский и английский языки. Версия **0.1.1 / code 2**, пакет `org.wayfarer.atlas`.

Entry-condition maps, citizenship comparison, access rankings and an on-device travel journal with reminders. No account, ads, purchases, subscriptions or cloud sync. Download the `-release.apk` file under **Assets** on the release page; see the [English installation steps](docs/user-guide.en.md#1-install-the-app).

## Установка и обновление

1. Откройте [последний выпуск](https://github.com/ArtiomNosov/wayfarer-atlas/releases/latest) на Android и скачайте файл с окончанием **`-release.apk`** из **Assets**.
2. Откройте файл и следуйте установщику Android. При запросе разрешите установку из конкретного браузера или файлового менеджера. [Пошаговая инструкция](docs/user-guide.ru.md#1-установите-приложение) объясняет системные сообщения.
3. Для обновления установите новый release APK **поверх прежнего, без удаления приложения**. Сохранение журнала при обновлении 0.1.0 → 0.1.1 проверено. Удаление приложения стирает журнал; экспорта и облачной резервной копии нет.

При первом запуске приложение попросит подтвердить предупреждение: сведения могут быть неполными, неточными или устаревшими. Перед покупкой билетов, подачей документов и каждой поездкой перепроверьте требования в официальной миграционной службе или консульстве. Подтверждение запоминается, текст доступен в настройках.

## Возможности

- Карта и список с поиском, фильтрами и ссылками на источники.
- Сравнение условий для двух гражданств и рейтинг с видимой методикой и покрытием.
- Локальный журнал: направления, даты, заметки и необязательные напоминания Android.
- Четыре источника справочника; два загружаются по кнопке, два обновляются с выпуском приложения.
- RU/EN без загрузки языковых пакетов, светлая и тёмная тема по настройке устройства.

Нет аккаунтов, облачной синхронизации, документов/фото, камеры/OCR, рекламы, платежей и подписок. После установки встроенные данные и журнал работают без сети. Обновление справочника и открытие сайтов источников требуют интернета.

## Обновление 0.1.1

- Добавлены три официальных источника к общему набору: Hong Kong Immigration Department (207 правил, прямое бесплатное CSV-обновление), Immigration New Zealand (60 правил NZeTA, проверенный встроенный срез) и сводка официального правила Россия → Макао (без визы до 30 дней).
- Россия → Гонконг: без визы до 14 дней по обычному загранпаспорту для краткого визита, с официальным источником и условиями.
- Общий результат: 38 822 пары, 213 стран/территорий выдачи паспорта, 199 направлений. Правила правительственных источников имеют приоритет перед общим набором; противоречащие официальные записи остаются UNKNOWN с обеими ссылками.
- Даты источников: CSV Гонконга содержит As at 2025-12-31. Сверка/получение 26.10.2026 — другая дата; её нельзя считать новой публикацией правил. У NZ/MO дата официального состояния не указана. Их проверенные срезы обновляются с версией приложения.
- Обязательный RU/EN дисклеймер до первого подтверждения «Понятно»; подтверждение локально, повторный просмотр в настройках. На первом запуске после обновления старой версии, где подтверждения ещё не было, он также появится.
- Последний корректный кеш хранится отдельно для каждого обновляемого источника; сбой одного не удаляет другие.

## Поведение и данные

Kotlin/Jetpack Compose: четыре раздела, светлая/тёмная тема, RU/EN, поиск, фильтры, источники и даты. Оба языка включены в пакет целиком для переключения без сети. Карта рисуется локально без WebView или платных картографических сервисов; доступен альтернативный список.

250 справочных кодов CLDR и **175 контуров** Natural Earth. Базовый community-набор содержит **38 612** пар правил для 197 гражданств; официальные дополнения описаны выше. Community-набор VisaChecker: версия **2026-08-11**, срез **2026-08-10**. Только **38** строк имеют индивидуальную дату проверки. Перед поездкой нужно обратиться к первоисточнику. Отсутствующие условия остаются неизвестными.

Безвизовый въезд, виза по прибытии и ETA входят в собственный индекс доступности; электронные визы считаются отдельно. Методика и покрытие видны в интерфейсе. Это не рейтинг Henley.

Пользователь запускает бесплатное обновление общего JSON с `raw.githubusercontent.com` и официального CSV с `www.immd.gov.hk`. Запрос не содержит поездок, заметок, гражданства, API-ключа или постоянного идентификатора. Эти хосты видят технические сведения о соединении. Проверенные срезы NZ/MO входят в пакет и обновляются с версией приложения. Старые, повреждённые и резко неполные обновления отклоняются; последняя корректная база остаётся локально.

Журнал хранится в закрытом хранилище с атомарной записью и сохранением повреждённого оригинала. Android backup/device transfer для данных приложения отключены. Напоминания WorkManager планируются примерно на 09:00 дня начала поездки; Android может отложить выполнение. Разрешение уведомлений на Android 13+ запрашивается при сохранении поездки с включённым напоминанием.

Лицензии, исходные файлы и SHA-256 сохранены в `data/`, атрибуция доступна в приложении. Подробнее: [источники](docs/data-sources.md).

## Повторная сборка

Откройте папку в Android Studio либо подготовьте изолированные инструменты:

```sh
python3 scripts/bootstrap.py
```

Первый запуск требует сети. Прочитайте лицензии SDK: SDK Manager покажет их перед принятием; после согласия можно использовать `--accept-sdk-licenses`. Для эмулятора добавьте `--with-emulator`. Инструменты сохраняются в ignored `.tooling/`. Скрипт поддерживает macOS и Linux; на Windows используйте Android Studio.

```sh
python3 scripts/sync-assets.py
bash scripts/gradle.sh testDebugUnitTest lintDebug lintRelease assembleDebug
python3 -m unittest discover -s data/tests -v
# При запущенном эмуляторе/подключённом тестовом Android:
bash scripts/gradle.sh connectedDebugAndroidTest
```

Официальная release-сборка подписывается ключом владельца, который отсутствует в репозитории. Для сопровождения официального приложения восстановите существующий ключ из защищённой копии в ignored `release-private/`. Не создавайте новый ключ поверх прежнего: APK с другим ключом не обновит установленную официальную версию. Для собственного нового приложения `python3 scripts/with-signing.py --create` создаёт локальный ключ без вывода паролей; перед его первой публикацией выберите собственный application ID.

```sh
python3 scripts/with-signing.py bash scripts/gradle.sh assembleRelease bundleRelease
python3 scripts/verify-artifacts.py
python3 scripts/package-release.py
```

Без окружения подписи Gradle может создать неподписанный release; используйте wrapper выше. **Сохраните защищённую копию ключа** и не передавайте содержимое `release-private/` в Git, чат или публичные артефакты. Для запуска своей тестовой сборки подпись владельца не нужна: используйте `assembleDebug`.

Выходы: `app/build/outputs/apk/release/app-release.apk` и `app/build/outputs/bundle/release/app-release.aab`. `dist/` формируется после проверок. AndroidTest содержит отдельный native screenshot capture; `scripts/export-store-screenshots.py` требует Pillow только в среде разработчика.

## Внешние шаги владельца

1. Указать публичное имя издателя, email поддержки и страну; окончательно выбрать название/пакет до первой публикации.
2. Заполнить черновик политики, разместить его по HTTPS и завершить Data safety по фактическому поведению.
3. Создать/верифицировать Play Console, сохранить ключ, загрузить AAB в тестовый трек и пройти применимые проверки.
4. Проверить физическое устройство и получить доступ к production, если Google требует его для нового аккаунта.

Все шаги объяснены в [иллюстрированном руководстве](docs/release/google-play-guide.ru.html). Локальная подготовка не заменяет проверку Google.
